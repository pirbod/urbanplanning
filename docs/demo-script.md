# Business Demo Script

## 1. Start on the Dashboard

Open UrbanTwin Azure Planning PoC on the Executive Overview dashboard. Explain that the platform coordinates active infrastructure projects, public comments, environmental risks, approval progress, and AI recommendations in one command center.

## 2. Open the Planning Map

Navigate to Interactive Planning Map. Point out that the map runs locally with Leaflet and mock GeoJSON, so no paid map keys or Azure subscription are required for the demo.

## 3. Toggle Planning Layers

Use the layer panel to toggle zoning, environmental risk areas, public feedback, projects, and mobility corridors. Explain that each layer can later be served from Cosmos DB, Blob Storage, or Azure Maps services.

## 4. Select Spree Riverside Mixed-Use Quarter

Click the Spree Riverside Mixed-Use Quarter marker or polygon. Show the detail panel with status, budget, approval progress, risk, and contextual actions.

## 5. Run AI Impact Analysis

Click Run AI impact analysis or open the AI Assistant page. Generate a traffic impact summary, environmental risk summary, stakeholder briefing, and mitigation action list. Stress that this is demo AI output and real decisions need expert review.

## 6. Show Environmental Risk

Open Environmental Impact Tracker. Highlight the Spree flood sensitivity buffer, protected habitat link, and heat island mitigation zone. Explain mitigation actions and linked projects.

## 7. Open Schedule View

Navigate to Project Scheduling. Show the Gantt-style timeline, filters, project cards, milestones, budgets, responsible teams, approval progress, and risk badges.

## 8. Submit Public Comment

Switch the role to Public User. Open Public Engagement and submit a comment for Spree Riverside Mixed-Use Quarter. Show that the new comment appears immediately with Pending review status.

## 9. Approve Document

Switch the role to Reviewer. Open Workflow Center, select an In review document, and approve it. Show the updated document status and audit trail.

## 10. Explain Azure Architecture and ROI

Open Azure Readiness. Walk through Static Web Apps, Functions, Cosmos DB, Blob Storage, Azure Maps, SignalR, AI Search, Azure ML or Azure OpenAI-ready services, Entra ID, and Terraform. Close with the ROI story: fewer disconnected tools, faster evidence gathering, better public transparency, and a lower-cost path to an enterprise-ready platform.
