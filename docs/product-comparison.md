# Product Comparison

This PoC combines selected capabilities from several urban planning and civic engagement tools into a lightweight Azure-native demonstrator.

| Product | Typical strength | UrbanTwin PoC direction |
| --- | --- | --- |
| ArcGIS Urban | Advanced 3D planning, zoning scenarios, and geospatial ecosystem depth | Lighter map-first command center with Azure deployment direction and local demo speed |
| Maptionnaire | Public participation, surveys, and map-based feedback | Adds public feedback workflows inside a broader planning operations dashboard |
| OpenCities Planner | Visual planning communication and 3D city engagement | Focuses on enterprise architecture, workflows, and data readiness rather than full 3D visualization |
| Commonplace | Citizen engagement and consultation management | Connects engagement to zoning, environmental risk, project scheduling, and document workflows |
| Plan4Better/GOAT | Accessibility, mobility, and planning analytics | Adds mobility corridors and impact summaries as part of a broader Azure-native operating model |
| OpenProject | Project management and scheduling | Adds planning-specific maps, zoning, public feedback, and environmental evidence |
| Felt | Collaborative web mapping | Adds role-aware planning workflows, proposal documentation, and Azure target architecture |

## Positioning

UrbanTwin Azure Planning PoC is not trying to replace mature specialist platforms in one sprint. It demonstrates a focused product thesis: combine the most valuable planning, engagement, scheduling, document, and AI workflows into a practical command center that can be shown locally and scaled toward Azure services when the business case is ready.

## Practical Differentiators

- Runs locally with no paid services for demos.
- Uses TypeScript mock data and GeoJSON-friendly shapes.
- Shows both business value and technical modernization path.
- Includes role-aware actions for Admin, Planner, Reviewer, and Public User.
- Includes Terraform starter notes for repeatable Azure deployment.
- Keeps AI output deterministic and reviewable for planning trust.
